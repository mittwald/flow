# Best Practices

- Verwende ein verständliches [Label](/components/content/label) wie „Datum".
- Wähle ein Datumsformat passend zum gewohnten Format des Users und zum Kontext.
- Wähle sinnvolle Defaultwerte.
- Schränke Eingaben bei Bedarf mit `minValue` und `maxValue` ein. So zeigst du
  zum Beispiel das frühestmögliche Datum eines Termins an.
