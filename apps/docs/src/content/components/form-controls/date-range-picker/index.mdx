# Best Practices

- Verwende ein verständliches [Label](/components/content/label) wie „Zeitraum".
- Wähle ein Datumsformat passend zum gewohnten Format des Users und zum Kontext.
- Wähle sinnvolle Defaultwerte.
- Schränke den auswählbaren Zeitraum bei Bedarf mit `minValue` und `maxValue`
  ein.
