# Best Practices

- Kennzeichne die Aktions-[Icons](/components/content/icon) klar und eindeutig.
  So vermeidest du Missverständnisse, etwa bei Löschen oder Herunterladen.
- Pflege sinnvolle Alt-Texte für die Bilder. Das sichert die
  Screenreader-Unterstützung.

---

# FitScreen

Standardmäßig passt sich der Inhalt der LightBox an die Bildschirmgröße an. Wird
die Property `fitScreen` auf `false` gesetzt, wird der Inhalt in seiner vollen
Höhe dargestellt. Falls der verfügbare Platz nicht ausreicht, erscheint eine
vertikale Scrollbar. Dieses Verhalten ist besonders hilfreich bei der
Darstellung von Inhalten mit großer vertikaler Ausdehnung, wie z. B.
mehrseitigen PDFs.

# Zoom

Mit `withZoom` lässt sich der Inhalt der LightBox vergrößern, z. B. um kleine
Schrift in einem Screenshot zu lesen. Ein Klick, ein Doppeltipp oder `Enter`
vergrößert auf das Doppelte, ein zweiter setzt den Zoom zurück. Mit dem Mausrad,
einer Pinch-Geste oder den Tasten `+` und `-` lässt sich die Vergrößerung
stufenlos bis zum Dreifachen anpassen. Das vergrößerte Bild kann den ganzen
Bildschirm ausfüllen und per Drag oder mit den Pfeiltasten verschoben werden. In
einer [Galerie](#galerie) gilt der Zoom für jedes Bild einzeln.

# Galerie

Innerhalb der LightBox kann eine `LightBoxGallery` verwendet werden. Diese kann
mit `LightBoxGalleryItems` gefüllt werden, welche die Platzierung von
[Images](/components/content/image) und
[ActionGroups](/components/actions/action-group) unterstützen.
