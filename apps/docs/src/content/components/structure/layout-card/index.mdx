# Best Practices

- Strukturiere den Content sinnvoll, zum Beispiel mit
  [Section](/components/structure/section) und
  [ColumnLayout](/components/structure/column-layout).
- Kombiniere die LayoutCard bei Bedarf mit einer
  [AccentBox](/components/structure/accent-box). So hebst du Inhalte besonders
  hervor.

---

# Kombiniere mit ...

## TabNavigation

Platziere die [TabNavigation](/components/navigation/tab-navigation) in einer
LayoutCard, um zwischen den Unterseiten zu navigieren. Der Inhalt der aktiven
Seite wird darunter in derselben LayoutCard dargestellt.
