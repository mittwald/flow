# Best Practices

- Nutze die AccordionGroup, sobald mehrere Accordions direkt untereinander
  stehen. Der Abstand des umgebenden Layouts liegt dann nur um den Block herum.
- Erlaube in der Regel, mehrere Accordions gleichzeitig zu öffnen. So lassen
  sich Inhalte vergleichen, und der angeklickte Titel springt nicht.

---

# Nur ein Accordion geöffnet

Mit `allowsMultipleExpanded={false}` schließt das Öffnen eines Accordions alle
anderen. Das eignet sich für Inhalte, die nacheinander gelesen werden, wie die
Schritte einer Anleitung.
