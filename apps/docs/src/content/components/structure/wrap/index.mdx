# Best Practices

- Nutze Wrap, wenn ein Element nur unter einer Bedingung um deinen Content
  liegen soll. Der Content steht so nur einmal im Code.
- Setze das optionale Element direkt in Wrap und deinen Content in dieses
  Element. Ist die Bedingung nicht erfüllt, entfällt nur das Element, der
  Content bleibt sichtbar.
