# Best Practices

- Nutze Wrap, wenn ein Element wie ein [Link](/components/navigation/link) nur
  unter einer Bedingung erscheinen soll. Der Content steht so nur einmal im
  Code.
- Lege genau ein Element in Wrap und den Content in dieses Element.
