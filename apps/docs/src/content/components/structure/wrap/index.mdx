# Best Practices

- Setze das optionale Element direkt in Wrap und deinen Content in dieses
  Element. Ist die Bedingung nicht erfüllt, entfällt nur das Element. Der
  Content bleibt sichtbar und steht trotzdem nur einmal im Code.
