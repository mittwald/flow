# Best Practices

- Wähle das Seitenverhältnis über `aspect` passend zum späteren
  Verwendungszweck.
- Biete dem User eine Möglichkeit zum Zurücksetzen. So kehrt er zum
  Ausgangszustand des Bildes zurück.

# Fehlerzustand

Kann das Bild nicht geladen oder nicht gelesen werden — eine abgelaufene URL,
ein 404 oder ein Bild von einer fremden Domain ohne CORS-Header —, zeigt der
ImageCropper eine Fehlermeldung anstelle des Ausschnitts. Über `onError` erfährt
die Anwendung davon, zum Beispiel um den Upload zurückzusetzen.

<LiveCodeEditor example="error" editorCollapsed />

Über `errorView` kann die Fehlermeldung ersetzt werden, etwa um dem User eine
Handlung anzubieten.

<LiveCodeEditor example="error-view" editorCollapsed />
