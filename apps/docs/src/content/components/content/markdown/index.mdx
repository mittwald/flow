# Best Practices

- Nutze Markdown vor allem für dynamische oder nutzergenerierte Texteingaben.
- Verwende für mehr Kontrolle über Layout und semantische Elemente stattdessen
  [Text](/components/content/text). Markdown wird als HTML ohne explizite
  Kontrolle über Elemente wie `<p>` oder `<h1>` gerendert.

# Zeilenumbrüche

Wie in CommonMark verbindet ein einfacher Zeilenumbruch im Text die Zeilen mit
einem Leerzeichen. Eine neue Zeile beginnt erst nach zwei Leerzeichen oder `\`
am Zeilenende, ein neuer Absatz nach einer Leerzeile.

Mit `preserveLineBreaks` bricht jeder Zeilenumbruch im Text auch die Zeile. Das
passt für Texte, die ohne Markdown-Kenntnis geschrieben werden.
