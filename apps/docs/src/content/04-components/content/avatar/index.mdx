# Best Practices

- **Wähle die passende Variante je nach Anwendungsfall.** Ein
  [Image](/04-components/content/image/overview) eignet sich für personalisierte
  Elemente wie Benutzerprofile, ein [Icon](/04-components/content/icon/overview)
  für wiederkehrende Inhalte.
- **Zeige Initialen, wenn kein passendes Image hinterlegt ist.**
- **Überlass die Color meist dem enthaltenen Element.** Setze über `color` nur
  dann eine feste Color, wenn sie die Unterscheidung verbessert.
- **Sorge dafür, dass die Bedeutung des Avatars aus dem Kontext hervorgeht.**
- **Nutze bei mehreren Avataren nebeneinander einen
  [AvatarStack](/04-components/content/avatar-stack/overview).**

# Status

Wird im Avatar das Property `status` gesetzt erhält der Avatar automatisch das
passende Icon und die passende Color. Dieses Property darf nur verwendet werden,
wenn der Status zusätzlich durch ein benachbartes Element (z. B.
[Text](/04-components/content/text/overview) oder
[Label](/04-components/content/label/overview)) eindeutig kommuniziert wird.
