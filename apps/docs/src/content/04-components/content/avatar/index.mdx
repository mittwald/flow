# Verwendung

Verwende einen Avatar, um ...

- einem übergeordneten Element eine visuelle Identität zu geben, z. B. um
  Einträge in einer [List](/04-components/structure/list/overview)
  unterscheidbar zu machen.
- dem User Personalisierung zu ermöglichen, z. B. Profil- oder Projektbilder.
- die visuelle Orientierung zu unterstützen, z. B. mit einem Icon-Avatar für die
  Zahlungsmethode in einer Bestellübersicht.

## Best Practices

Achte bei der Verwendung eines Avatars darauf, dass ...

- je nach Anwendungsfall die passende Variante gewählt wird: ein
  [Image](/04-components/content/image/overview) für personalisierte Elemente
  wie Benutzerprofile, ein [Icon](/04-components/content/icon/overview) für
  wiederkehrende Inhalte.
- Initialen angezeigt werden, wenn kein passendes Image hinterlegt ist.
- die Color meist vom enthaltenen Element bestimmt wird; setze über `color` nur
  dann eine feste Color, wenn es die Unterscheidung verbessert.
- aus dem Kontext klar hervorgeht, welche Bedeutung der Avatar hat.
- bei mehreren nebeneinander ein
  [AvatarStack](/04-components/content/avatar-stack/overview) verwendet wird.

# Status

Wird im Avatar das Property `status` gesetzt erhält der Avatar automatisch das
passende Icon und die passende Color. Dieses Property darf nur verwendet werden,
wenn der Status zusätzlich durch ein benachbartes Element (z. B.
[Text](/04-components/content/text/overview) oder
[Label](/04-components/content/label/overview)) eindeutig kommuniziert wird.
