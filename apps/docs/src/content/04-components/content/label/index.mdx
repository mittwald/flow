# Verwendung

Verwende ein Label, um ...

- die Eingabeanforderungen an Components innerhalb von Formularen (z. B.
  [TextField](/04-components/form-controls/text-field/overview),
  [NumberField](/04-components/form-controls/number-field/overview),
  [RadioGroup](/04-components/form-controls/radio-group/overview), ...) zu
  erläutern.
- eine Information in Kontext zu setzen, z. B. beim
  [LabeledValue](/04-components/content/labeled-value/overview).

## Best Practices

Achte bei der Verwendung eines Labels darauf, dass ...

- es kurz (1–3 Wörter), prägnant und in einfacher Sprache formuliert ist.
- es jederzeit vollständig sichtbar und einzeilig ist.
- es das Feld als Substantiv benennt (z. B. „E-Mail-Adresse“ statt „E-Mail
  eingeben“).
- Formatierungshinweise über die FieldDescription im
  [TextField](/04-components/form-controls/text-field/overview) gegeben werden.

# States

Ein Label hat zwei States:

- **Default** – das Label wird in seiner Standarddarstellung angezeigt.
- **Disabled** – das Label beschreibt häufig komplexere Components und übernimmt
  automatisch deren State. Ist z. B. ein
  [TextField](/04-components/form-controls/text-field/overview) oder
  [NumberField](/04-components/form-controls/number-field/overview) gerade
  **disabled**, nimmt das Label denselben State an.
