# Code-Beispiel

Schließe Code-Fragmente in `<InlineCode />` ein — meist innerhalb einer
[Text](/04-components/content/text/overview)-Component.

<LiveCodeEditor />

---

# Best Practices

- **Setze InlineCode sparsam ein.** Zu viele InlineCodes machen einen Text
  unleserlich.
- **Nutze InlineCode nur für kurze Beispiele.** Für längere Code-Beispiele
  eignet sich der [CodeBlock](/04-components/content/code-block/overview).

---

# Color

Zusätzlich zur Standard-Color kann InlineCode in **Light** und **Dark**
dargestellt werden, wenn die Standard-Color auf farbigen oder dekorativen
Hintergründen keinen ausreichenden Kontrast (mind. 4,5:1) bietet. Wann welche
Color passt, beschreibt
[Color](/02-foundations/01-design/02-colors#light-und-dark-color).
