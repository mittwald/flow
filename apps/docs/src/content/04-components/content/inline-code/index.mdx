# Code-Beispiel

<LiveCodeEditor />

---

# Verwendung

Verwende InlineCode, um einzelne Code-Fragmente wie Funktionsnamen, Variablen,
Dateinamen oder Pfade im Fließtext darzustellen.

## Best Practices

Achte bei der Verwendung von InlineCode darauf, dass ...

- er sparsam eingesetzt wird, da zu viele InlineCodes einen Text unleserlich
  machen.
- er nur für kurze Beispiele verwendet wird — bei längeren Code-Beispielen
  empfiehlt sich der [CodeBlock](/04-components/content/code-block/overview).

# Color

Zusätzlich zur Standard-Color kann InlineCode in **Light** und **Dark**
dargestellt werden, wenn die Standard-Color auf farbigen oder dekorativen
Hintergründen keinen ausreichenden Kontrast (mind. 4,5:1) bietet. Wann welche
Color passt, beschreibt
[Color](/02-foundations/01-design/02-colors#light-und-dark-color).
