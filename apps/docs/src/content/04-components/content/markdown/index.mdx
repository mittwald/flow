# Best Practices

- **Nutze Markdown vor allem für dynamische oder nutzergenerierte
  Texteingaben.**
- **Verwende für mehr Kontrolle über Layout und semantische Elemente stattdessen
  [Text](/04-components/content/text/overview).** Markdown wird als HTML ohne
  explizite Kontrolle über Elemente wie `<p>` oder `<h1>` gerendert.

# Color

Zusätzlich zur Standard-Color kann Markdown in **Light** und **Dark**
dargestellt werden, wenn die Standard-Color auf farbigen oder dekorativen
Hintergründen nicht gut funktioniert. Wann welche Color passt, beschreibt
[Color](/02-foundations/01-design/02-colors#light-und-dark-color).
