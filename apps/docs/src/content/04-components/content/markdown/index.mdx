# Verwendung

Verwende Markdown, um dynamische oder nutzergenerierte Texteingaben im
Markdown-Format darzustellen (z. B. in Kommentarfunktionen oder im
[Chat](/04-components/chat/chat/overview)).

## Best Practices

Achte bei der Verwendung von Markdown darauf, dass ...

- sie vor allem für dynamische oder nutzergenerierte Texteingaben genutzt wird.
- für mehr Kontrolle über Layout und semantische Elemente (z. B. `<p>` oder
  `<h1>`) stattdessen [Text](/04-components/content/text/overview) verwendet
  wird, da Markdown als HTML ohne explizite Kontrolle gerendert wird.
