# Best Practices

- Zeige nicht zu viele [Avatare](/04-components/content/avatar/overview)
  gleichzeitig. Empfohlen sind höchstens fünf; für die verbleibende Anzahl nutzt
  du die Property `totalCount`.
- Zeige bei Bedarf per Klick mehr Informationen an. Das kann zum Beispiel ein
  [Modal](/04-components/overlays/modal/overview) mit dem Benutzerprofil sein.
- Halte die Avatare konsistent zur Darstellung an anderen Stellen. Nutze etwa
  das hochgeladene Profilbild statt eines generischen
  User-[Icons](/04-components/content/icon/overview).

# Total Count

Über die Property `totalCount` lässt sich die Gesamtzahl der
[Avatare](/04-components/content/avatar/overview) angeben. Ist `totalCount`
größer als die Anzahl der angezeigten Avatare, wird ein zusätzlicher Counter mit
der verbleibenden Anzahl angezeigt.

# Klickbar

Mit `onPress` lassen sich Avatare klickbar machen, sodass zu den jeweiligen
Avataren beispielsweise weitere Informationen im
[Modal](/04-components/overlays/modal/overview) angezeigt werden können.
