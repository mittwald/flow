# Verwendung

Verwende einen Button, um ...

- eine Aktion oder einen Befehl in einem Formular oder einer Oberfläche
  auszuführen.
- ein [Modal](/04-components/overlays/modal/overview) zu öffnen.

Achte bei der Verwendung eines Buttons darauf, dass ...

- der Text oder das Icon die auszuführende Aktion eindeutig beschreibt.
- die visuelle Hierarchie der Wichtigkeit der Aktion entspricht.
- die gewählte Variante die Bedeutung der Aktion unterstützt.
- der User nach dem Ausführen der Aktion ein visuelles Feedback erhält.

---

# Variants

Verwende die unterschiedlichen Varianten, um Buttons in einer Oberfläche eine
visuelle Hierarchie zu geben:

- **Solid** für Hauptaktionen, die eine hohe Aufmerksamkeit erfordern.
- **Soft** für Nebenaktionen, die visuell keine hohe Aufmerksamkeit erfordern.
- **Outline**, wenn eine Aktion sichtbar und klar erkennbar sein soll, ohne
  dabei die Aufmerksamkeit eines gefüllten Buttons zu beanspruchen.
- **Plain** für weniger wichtige oder versteckte Aktionen.

# Color

Farben unterstützen die visuelle Hierarchie zusätzlich. Verwende:

- **Primary**, um Hauptaktionen standardmäßig visuell hervorzuheben.
- **Secondary**, um Nebenaktionen abzuschwächen und neutral darzustellen.
- **Accent**, um die positive Bedeutung einer Aktion zu stärken. Diese Farbe
  wird daher vor allem im Kontext von Erstellungs-, Speicher- oder
  Bestellvorgängen verwendet.
- **Danger**, um negative Konsequenzen einer Aktion zu verdeutlichen. Sie wird
  beispielsweise für Lösch- oder Kündigungsaktionen verwendet.

# Sizes

Medium ist die Standardgröße und wird für die meisten Buttons verwendet. Small
kann genutzt werden, wenn weniger Platz vorhanden ist. Vermeide es,
unterschiedliche Button-Größen direkt nebeneinander zu verwenden.

# States

**Disabled** zeigt an, dass eine Aktion nicht ausgeführt werden kann. Achte
darauf, dass aus dem Kontext klar wird, warum die Aktion nicht zur Verfügung
steht.

Die States **Pending**, **Succeeded** und **Failed** geben dem User zusätzliches
visuelles Feedback darüber, dass im Hintergrund eine Aktion läuft, erfolgreich
abgeschlossen wurde oder fehlgeschlagen ist. Um diese States zu steuern, kann
die [Action](/04-components/actions/action/overview)-Komponente genutzt werden.

# Content

Der Content-Bereich eines Buttons kann entweder Text, ein Icon oder Text mit
einem Icon am Ende enthalten.

## Icon

Wenn ausschließlich ein Icon verwendet wird, sollte das `aria-label` den
Verwendungszweck beschreiben. Ein Tooltip kann zusätzlich verdeutlichen, wofür
die Aktion gedacht ist.

## Text + Icon

Bei der Kombination aus Text und Icon sollte das Icon keinen rein dekorativen
Zweck erfüllen. Zum Beispiel kann ein Chevron-Icon darauf hinweisen, dass der
Button ein Dropdown öffnet.
