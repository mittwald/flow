# Best Practices

- **Platziere den CopyButton unmittelbar neben dem zu kopierenden Text.** Die
  [Align](/04-components/structure/align/overview)-Component hilft bei der
  Anordnung.
- **Nutze standardmäßig die Secondary Color.** So bleibt der CopyButton trotz
  häufiger Nutzung in der Oberfläche optisch zurückhaltend.
