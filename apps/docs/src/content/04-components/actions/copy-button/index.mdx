# Verwendung

Verwende einen CopyButton, um Inhalte – beispielsweise aus einem
[LabeledValue](/04-components/content/labeled-value/overview) oder einfachem
[Text](/04-components/content/text/overview) – aus der Benutzeroberfläche zu
kopieren.

## Best Practices

Achte bei der Verwendung eines CopyButtons darauf, dass ...

- er sich in unmittelbarer Nähe zum zu kopierenden Text befindet. Um ihn direkt
  neben einem Text zu platzieren, kann die
  [Align](/04-components/structure/align/overview)-Component verwendet werden.
- seine Standard-Color **Secondary** ist. Ausnahmen sind möglich, z. B. wenn
  sich der CopyButton auf einem farbigen Hintergrund befindet – dann können die
  Color **Dark** oder **Light** verwendet werden.
