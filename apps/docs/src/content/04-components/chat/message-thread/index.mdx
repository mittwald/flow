# Code-Beispiel

Schließe mehrere [Messages](/04-components/chat/message/overview) in einen
`<MessageThread />` ein, um einen Gesprächsverlauf darzustellen. Ein
`<MessageSeparator />` hebt wichtige Ereignisse hervor.

<LiveCodeEditor />

---

# Best Practices

- **Halte die zeitliche Abfolge der Messages konsistent.**
- **Zeichne Absender und Antwortender über das `type`-Property als `sender` bzw.
  `responder` aus.**
- **Hebe wichtige Ereignisse mit einem `<MessageSeparator />` hervor.** Dazu
  zählen etwa Statusänderungen oder der Eintritt neuer Teilnehmer.
