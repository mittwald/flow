# Grundlagen

Die Chat-Component dient dem Aufbau eines vollständigen Chat-Interfaces. Sie
kombiniert einzelne Components wie den
[MessageThread](/04-components/chat/message-thread/overview) und die Texteingabe
durch die [TextArea](/04-components/form-controls/text-area/overview) zu einer
funktionalen Einheit. Dadurch entfällt für Entwickler die Notwendigkeit, diese
Components manuell zusammenzustellen.

## Best Practices

Achte bei der Verwendung einer Chat-Component darauf, dass ...

- das `aria-label` der Texteingabe bei abweichender Funktionalität angepasst
  wird.
- der Wert der `height` Property gut gewählt ist, um ausreichend Platz zum Lesen
  des Chats zu gewährleisten.

## Verwendung

Verwende die Chat-Component, um einen konsistenten und wiederverwendbaren
Chatbereich in einer Anwendung bereitzustellen.

# Playground

Textinput. Mit der `height` Property lässt sich die Höhe des Chats festlegen.
Gleichzeitig sorgt sie dafür, dass die Texteingabe am unteren Rand platziert
wird.

## Upload

[FileField](/04-components/form-controls/file-field/overview) genutzt werden,
über das User Dateien auswählen können. Die hochgeladenen Dateien können dann in
einer [FileCardList](/04-components/upload/file-card-list/overview) dargestellt
werden.
