# Grundlagen

## Best Practices

Achte bei der Verwendung der Message darauf, dass ...

- mehrere Messages in einem
  [MessageThread](/04-components/chat/message-thread/overview) gruppiert werden.
- die [Markdown](/04-components/content/markdown/overview)-Component genutzt
  wird, wenn eine Texteingabe in Markdown zu erwarten ist.
- das [ContextMenu](/04-components/actions/context-menu/overview) nicht
  überladen wird und nur direkt relevante Aktionen (z. B. Bearbeiten und
  Löschen) enthält.

## Verwendung

Verwende die Message, um ...

- einzelne Nachrichten eines Chats darzustellen.
- in Kombination mit dem
  [MessageThread](/04-components/chat/message-thread/overview) einen
  Gesprächsverlauf abzubilden.

# Mit Action

Eine Message kann um einen [Button ](/04-components/actions/button/overview)
oder eine [ActionGroup](/04-components/actions/action-group/overview) erweitert
werden. Die Actions sollten dabei immer in direktem Bezug zum Inhalt der Message
stehen und passende Interaktion ermöglichen.

# Custom Color

Im Default sind `sender` blau und `responder` grau hinterlegt. Wenn eine
Nachricht gezielt hervorgehoben werden soll, zum Beispiel als System-Nachricht
oder als interne Notiz, kann der Message eine customColor mitgegeben werden.
Dabei muss der Entwickler selbst auf einen ausreichenden Kontrast zur Textfarbe
achten.
