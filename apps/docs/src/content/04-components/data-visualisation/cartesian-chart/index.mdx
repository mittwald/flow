# Verwendung

Verwende ein CartesianChart, um ...

- Trends von Metriken über längere Zeiträume hinweg zu zeigen.
- den relativen Anteil mehrerer Dimensionen an einem Gesamtwert darzustellen
  (mit Area-Darstellung).
- Veränderungen bei einer oder mehreren Dimensionen miteinander zu vergleichen.

## Best Practices

Achte bei der Verwendung eines CartesianCharts darauf, dass ...

- die x-Achse immer zeitbasiert ist.
- Dimensionen mit [Categorical Colors](/02-foundations/01-design/02-colors)
  dargestellt werden.
- bei der Area-Darstellung die Areas nach Größe sortiert werden, mit der größten
  Area unten.
- die Anzahl der dargestellten Dimensionen übersichtlich bleibt, um Lesbarkeit
  sicherzustellen.

# Darstellungstypen

Im CartesianChart können unterschiedliche Darstellungstypen wie `<Area />`,
`<Line />` oder eine Kombination aus beiden verwendet werden.

## Line

Zeigt die Entwicklung einzelner Objekte über einen Zeitraum und ermöglicht den
Vergleich zwischen ihnen.

eigene Farben verwendet werden. Es sollte sichergestellt sein, dass Farben, die
direkt nebeneinander liegen, einen ausreichenden Kontrast zueinander haben.

# Mit EmptyView

Der EmptyView wird angezeigt, sobald die Property `data` des Charts entweder ein
leeres Array enthält oder `undefined` ist. Er dient dazu, leere Zustände visuell
zu kennzeichnen und bietet Orientierung bei Ausnahmefällen wie Ladefehlern,
fehlgeschlagenen Datenabfragen oder nicht vorhandenen Ergebnissen.
