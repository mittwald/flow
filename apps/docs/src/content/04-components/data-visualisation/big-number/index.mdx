# Verwendung

Verwende eine BigNumber, um ...

- zentrale Kennzahlen auf einem Dashboard schnell erfassbar zu machen.
- den Fokus gezielt auf einen einzelnen Wert zu lenken.

## Best Practices

Achte bei der Verwendung einer BigNumber darauf, dass ...

- der dargestellte Wert für die User eine unmittelbare Relevanz oder
  Aussagekraft besitzt.
- ausreichend Raum zur Verfügung steht, damit die Zahl optisch wirken kann und
  nicht mit anderen Elementen konkurriert.
