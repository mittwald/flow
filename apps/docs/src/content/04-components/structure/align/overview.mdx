Align heißt jetzt [Combine](/04-components/structure/combine/overview). Der neue
Name beschreibt, was die Component tut: Sie gibt bekannten Kombinationen von
Components eine feste, korrekte Anordnung. Der alte Name führte dagegen
regelmäßig zu Verwechslungen mit der `align` Property von
[Flex](/04-components/structure/flex/overview).
