# Best Practices

- **Verwende nur die unterstützten Kombinationen.**
- **Nutze Align nicht als generisches Layout-Tool.** Für eine freie Anordnung
  ist [Flex](/04-components/structure/flex/overview) vorgesehen.
- **Nutze neben der Anordnung auch visuelle Anpassungen wie das Setzen von
  Colors.**
