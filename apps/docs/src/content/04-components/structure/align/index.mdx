# Verwendung

Verwende Align, um ...

- vorab definierte Components (z. B.
  [Button](/04-components/actions/button/overview) und
  [TextField](/04-components/form-controls/text-field/overview)) sinnvoll
  anzuordnen.
- wiederkehrende UI-Patterns konsistent umzusetzen, ohne für jede Kombination
  eine eigene Component zu entwickeln.

## Best Practices

Achte bei der Verwendung von Align darauf, dass ...

- nur die unterstützten Kombinationen verwendet werden.
- es nicht als generisches Layout-Tool dient. Für eine freie Anordnung ist
  [Flex](/04-components/structure/flex/overview) vorgesehen.
- neben der Anordnung auch visuelle Anpassungen wie das Setzen von Farben
  möglich sind.
