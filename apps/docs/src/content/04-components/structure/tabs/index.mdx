# Verwendung

Verwende Tabs, um komplexe Inhalte in kleinere, übersichtlichere Ansichten zu
gliedern.

## Best Practices

Achte bei der Verwendung von Tabs darauf, dass ...

- innerhalb eines Tabs thematisch verwandter Content gruppiert wird.
- die Reihenfolge nach Wichtigkeit oder Häufigkeit der Nutzung erfolgt.
- jeder Tab eigenständig verständlich ist und eine kurze, deutliche Beschriftung
  hat.
- sie nicht zur Navigation eingesetzt werden – Tabs schalten ausschließlich
  Inhalte innerhalb derselben Seite um, ohne zu einer anderen Seite bzw. URL zu
  navigieren.

## Tabs vs. TabNavigation

Flow bietet mit Tabs und der
[TabNavigation](/04-components/navigation/tab-navigation/overview) zwei ähnlich
aussehende Components, die sich in der Verwendung klar unterscheiden.

<DoAndDont>
  <Info heading="Verwende Tabs, um ...">
    Inhalte innerhalb derselben Seite umzuschalten, ohne zu navigieren.
  </Info>

  <Info heading="Verwende eine TabNavigation, um ...">
    zwischen gleichrangigen Unterseiten zu navigieren.
  </Info>
</DoAndDont>

# Reihenfolge der Tabs

Werden innerhalb eines Tabs Inhalte nachgeladen, kann sich durch das Rerendering
die Reihenfolge der Tabs ändern. Um das zu verhindern, lagere den Tab-Inhalt in
eine eigene Component aus und umschließe sie mit einem `Suspense`.

```tsx
<Tabs>
  <Tab>
    <TabTitle>Tab 1</TabTitle>
    <Suspense>
      <Tab1Content />
    </Suspense>
  </Tab>
  <Tab>
    <TabTitle>Tab 2</TabTitle>
    <Suspense>
      <Tab2Content />
    </Suspense>
  </Tab>
</Tabs>
```
