# Grundlagen

Flex wurde eingeführt, um eine flexible Anordnung von Inhalten auf Basis der
CSS-Flexbox zu ermöglichen. So bleibt unser Designsystem offen genug, um auch
spezifische, schwer zu standardisierende Anforderungen und Layouts abzubilden.

## Best Practices

Achte bei der Verwendung von Flex darauf, dass ...

- sie nicht für Layouts verwendet wird, die mit
  [Align](/04-components/structure/align/overview) kombiniert werden können und
  einem festen UI-Pattern folgen.
- sie gezielt für Sonderfälle genutzt wird – in den meisten Fällen bietet unser
  Designsystem bereits eine passende Lösung.

## Flex vs. Align

Flex und [Align](/04-components/structure/align/overview) sind sich als
Layout-Components sehr ähnlich. Um die beiden besser unterscheiden zu können,
hier ein paar hilfreiche Anhaltspunkte.

<DoAndDont>
  <Plain heading="Verwende Flex, um ...">
    - individuelle Layouts zu gestalten, die keinem festen UI Pattern folgen.
    - bewusst vom Standard des Designsystems abzuweichen.

  </Plain>

  <Plain heading="Verwende Align, um ...">
    - vorab definierte Components miteinander zu kombinieren und automatisch anzuordnen.
    - wiederkehrende UI Patterns konsistent umzusetzen.

  </Plain>
</DoAndDont>

# Playground

<Alert>
  <Heading>Individuelles Layout mit Flex</Heading>
  <Content>
    Der Einsatz von Flex führt zu individuellen Layouts, die vom Designsystem
    abweichen. Das kann den Wartungsaufwand erhöhen und für User zu ungewohnten
    Interaktionen führen. Nutze Flex daher nur für gezielte, kleine
    Layout-Anpassungen und überlege sorgfältig, ob der Einsatz wirklich
    notwendig ist.
  </Content>
</Alert>
