# Grundlagen

Combine gibt bekannten Kombinationen von Components eine feste, korrekte
Anordnung. Sie übernimmt die kniffligen Details – etwa einen
[Avatar](/04-components/content/avatar/overview), der optisch zum Text zentriert
wird, oder einen [Button](/04-components/actions/button/overview), der trotz
Label und FieldDescription auf der Höhe des Eingabefelds sitzt. So bleiben
wiederkehrende Kombinationen einheitlich, ohne für jede eine eigene Component zu
entwickeln.

## Best Practices

Achte bei der Verwendung von Combine darauf, dass ...

- nur die im Overview genannten Components kombiniert werden können. Andere
  Kombinationen erzeugen keine Anordnung.
- neben der Anordnung auch visuelle Anpassungen (z. B. Color und Size der
  enthaltenen Components) vorgenommen werden.
- sie kein generisches Layout-Tool ist. Für eine freie Anordnung ist
  [Flex](/04-components/structure/flex/overview) vorgesehen.

## Verwendung

Verwende Combine, um ...

- eine der im Overview dokumentierten Kombinationen darzustellen.
- wiederkehrende UI-Patterns konsistent umzusetzen.

## Combine vs. Flex vs. ColumnLayout

Alle drei ordnen Components an – aber auf unterschiedlichen Ebenen. Die Frage
ist nicht, welche Component flexibler ist, sondern ob es für den Fall bereits
ein Pattern gibt.

<DoAndDont>
  <Plain heading="Verwende Combine, um ...">
    - eine der dokumentierten Kombinationen darzustellen.
    - die Anordnung dem Designsystem zu überlassen.

  </Plain>

  <Plain heading="Verwende Flex, um ...">
    - ein individuelles Layout zu gestalten, das keinem Pattern folgt.
    - bewusst vom Standard des Designsystems abzuweichen.

  </Plain>

  <Plain heading="Verwende ColumnLayout, um ...">
    - Content in Spalten zu gliedern, die je Breakpoint umbrechen.
    - Seiten- und Formular-Layouts zu strukturieren.

  </Plain>
</DoAndDont>

Steht die gewünschte Kombination im Overview, ist Combine die richtige Wahl –
sie hält die Anordnung auch dann korrekt, wenn sich Inhalte oder Breakpoints
ändern. Erst wenn keine passende Kombination existiert, ist
[Flex](/04-components/structure/flex/overview) das richtige Werkzeug. Für
Layouts über mehrere Spalten ist das
[ColumnLayout](/04-components/structure/column-layout/overview) zuständig.
