# Best Practices

- Strukturiere den Content sinnvoll, zum Beispiel mit
  [Section](/04-components/structure/section/overview) und
  [ColumnLayout](/04-components/structure/column-layout/overview).
- Kombiniere die LayoutCard bei Bedarf mit einer
  [AccentBox](/04-components/structure/accent-box/overview). So hebst du Inhalte
  besonders hervor.

---

# Kombiniere mit ...

## TabNavigation

Platziere die [TabNavigation](/04-components/navigation/tab-navigation/overview)
in einer LayoutCard, um zwischen den Unterseiten zu navigieren. Der Inhalt der
aktiven Seite wird darunter in derselben LayoutCard dargestellt.
