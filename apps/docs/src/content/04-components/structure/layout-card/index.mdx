# Verwendung

Verwende eine LayoutCard, um ...

- einen oder mehrere Content-Bereiche auf einer Seite zu erzeugen.
- eine Kacheloptik auf einem Dashboard darzustellen.
- eine äußere Hülle für ein Navigationsmenü zu gestalten.

## Best Practices

Achte bei der Verwendung einer LayoutCard darauf, dass ...

- der Content innerhalb sinnvoll strukturiert ist, z. B. mit den Components
  [Section](/04-components/structure/section/overview) und
  [ColumnLayout](/04-components/structure/column-layout/overview).
- sie bei Bedarf mit einer
  [AccentBox](/04-components/structure/accent-box/overview) kombiniert wird, um
  Inhalte besonders hervorzuheben.
