# Grundlagen

## Best Practices

Achte bei der Verwendung einer Navigation darauf, dass ...

- Menüeinträge kurz, prägnant und verständlich benannt sind.
- [Icons](/04-components/content/icon/overview) nur ergänzend und nicht als
  alleinige Information eingesetzt werden.
- maximal 7 bis 8 Menüeinträge in einer Gruppe enthalten sind, sodass die
  Navigation übersichtlich bleibt.
- einklappbare Gruppen den Überblick verbessern, jedoch die Orientierung
  erschweren können.

## Verwendung

Verwende eine Navigation, um Usern einen schnellen Zugriff auf Unterseiten zu
ermöglichen.

# Mit einklappbaren Gruppen

Mit der Property `collapsable` können Menügruppen ein- und ausklappbar gemacht
werden. Gerade bei umfangreichen Navigationen hilft dies, die Übersicht zu
wahren.

# Mit Badge

erweitert werden um zusätzliche Metainformationen wie „New“ oder „Beta“
anzuzeigen. Für Anwendungsfälle wie ein Benachrichtigungscenter kann außerdem
ein [CounterBadge](/04-components/status/counter-badge/overview) verwendet
werden.
