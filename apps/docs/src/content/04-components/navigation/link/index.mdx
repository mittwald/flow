# Verwendung

Verwende einen Link, um ...

- den User zu einer neuen Seite innerhalb der Anwendung oder zu einer externen
  Seite zu navigieren.
- auf einen Ankerpunkt auf der Seite für eine Information zu scrollen.
- einen Download zu starten.

## Best Practices

Achte bei der Verwendung eines Links darauf, dass ...

- für Navigation bevorzugt Links und für Aktionen Buttons verwendet werden. Eine
  Ausnahme können hervorgehobene Call-to-Actions sein, bei denen ein
  Button-ähnliches Erscheinungsbild für eine Navigation sinnvoll ist.
- die Intention des Links klar erkennbar ist und der Linktext kurz und prägnant
  bleibt.
- ein `aria-label` ergänzt wird, wenn der Linktext allein nicht eindeutig ist.
- externe Links immer in einem neuen Tab öffnen, interne Links dagegen im
  gleichen Tab.

# Externe Links und Downloads

Interne Links öffnen sich immer in dem Tab, in dem der User sich gerade
befindet. Der User kann jedoch selbst entscheiden, ob er den Link lieber in
einem neuen Tab öffnen möchte.

## Externer Link

Externe Links – also Verweise auf eine andere Domain – öffnen sich immer in
einem neuen Tab. Sobald `target="_blank"` gesetzt ist, wird automatisch das
`IconExternalLink` angezeigt, um dieses Verhalten zu verdeutlichen.
