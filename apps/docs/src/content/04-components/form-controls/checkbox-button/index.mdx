# Verwendung

Verwende einen CheckboxButton, um ...

- dem User die Auswahl einer oder mehrerer Optionen zu ermöglichen.
- einzelne Zustimmungen (z. B. AGB) vom User einzuholen.

## Best Practices

Achte bei der Verwendung eines CheckboxButtons darauf, dass ...

- er immer eine kurze, eindeutige Beschriftung hat.
- der initiale Zustand nachvollziehbar und sinnvoll gewählt ist.
- bei mehreren CheckboxButtons die Reihenfolge logisch und nachvollziehbar ist
  (siehe [CheckboxGroup](/04-components/form-controls/checkbox-group/overview)).
- du für eine kompaktere, unauffälligere Auswahl alternativ die
  [Checkbox](/04-components/form-controls/checkbox/overview) nutzt.

## CheckboxButton vs. Switch

Mit den Components CheckboxButton und
[Switch](/04-components/form-controls/switch/overview) können Optionen
aktiviert/ausgewählt werden.

<DoAndDont>
  <Plain heading="Verwende einen CheckboxButton, um z. B. ...">
    - dem User eine Auswahloption zur Bestätigung zu geben.
    - Auswahlmöglichkeiten in einem Formular anzubieten, die gespeichert werden müssen.

  </Plain>

  <Plain heading="Verwende einen Switch, um z. B. ...">
    - eine Funktion direkt zu aktivieren oder zu deaktivieren.
    - eine Einstellung sofort zu ändern, ohne sie separat speichern zu müssen.

  </Plain>
</DoAndDont>
