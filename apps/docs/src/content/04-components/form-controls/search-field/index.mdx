# Code-Beispiel

Das SearchField bringt selbst keine Suchlogik mit. Verarbeite die Eingabe über
`onChange` bzw. `onSubmit` oder binde das Feld in eine
[Form (React Hook Form)](/04-components/react-hook-form/form/overview) ein.

# Best Practices

- **Gib visuelles Feedback bei Ladezuständen oder Fehlern.** Ein Beispiel ist
  der Hinweis, dass keine Suchergebnisse gefunden wurden.
- **Positioniere das SearchField leicht zugänglich und gut sichtbar.** Platziere
  es dort, wo User eine Suche erwarten.
