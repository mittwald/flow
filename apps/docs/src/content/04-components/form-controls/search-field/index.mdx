# Best Practices

- Gib visuelles Feedback bei Ladezuständen oder Fehlern. Ein Beispiel ist der
  Hinweis, dass keine Suchergebnisse gefunden wurden.
- Positioniere das SearchField leicht zugänglich und gut sichtbar. Platziere es
  dort, wo User eine Suche erwarten.
