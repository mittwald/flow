# Verwendung

Verwende ein SearchField, um ...

- große Datenmengen (z. B. in der
  [List](/04-components/structure/list/overview)) gezielt und effizient zu
  durchsuchen.
- Usern das schnelle Auffinden von Inhalten, Produkten oder Daten zu
  ermöglichen.
- die Navigation innerhalb komplexer Anwendungen oder Websites zu unterstützen.

## Best Practices

Achte bei der Verwendung eines SearchFields darauf, dass ...

- visuelles Feedback bei Ladezuständen oder Fehlern (z. B. keine Suchergebnisse
  gefunden) gegeben wird.
- sie leicht zugänglich und gut sichtbar positioniert ist, vorzugsweise an
  Stellen, an denen User eine Suche erwarten.
