# Verwendung

Verwende ein Select, um ...

- eine Einfachauswahl aus mehreren Optionen bereitzustellen.
- dem User eine kompakte Auswahl anzubieten, bei der im geschlossenen Zustand
  nur die gewählte Option sichtbar ist.
- in Formularen eine eindeutige Auswahl aus vordefinierten Werten einzufordern.

## Best Practices

Achte bei der Verwendung eines Selects darauf, dass ...

- das [Label](/04-components/content/label/overview) kurz und deutlich
  formuliert ist.
- ein Placeholder mit klarer Handlungsaufforderung (z. B. „Sprache wählen")
  verwendet wird, wenn kein sinnvoller Default-Wert existiert.
- die Optionen verständlich und konsistent benannt sind.
- die Anzahl der Optionen überschaubar bleibt. Bei sehr vielen Einträgen kann z.
  B. eine [ComboBox](/04-components/form-controls/combo-box/overview) die
  bessere Wahl sein.
- die Optionen in einer sinnvollen, nachvollziehbaren Reihenfolge dargestellt
  werden, z. B. alphabetisch, thematisch oder nach Relevanz.
