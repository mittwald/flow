# Best Practices

- Unterstütze die visuelle Darstellung immer mit ergänzendem Kontext. Dazu
  eignet sich zum Beispiel eine Beschriftung.
- Nutze eine konsistente Skalierung von 0 bis 5 Sternen innerhalb eines
  Interfaces.
