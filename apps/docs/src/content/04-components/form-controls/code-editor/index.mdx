# Code-Beispiel

Gib den Inhalt des `<CodeEditor />` über das `value` Property an und setze mit
dem `language` Property die Programmiersprache (s.
[unterstützte language imports](https://github.com/mittwald/flow/tree/main/packages/components/src/components/CodeEditor/languages/all.ts)),
damit der Code korrektes Syntax-Highlighting erhält.

# Verwendung

Verwende einen CodeEditor, um Code direkt innerhalb der Oberfläche zu schreiben
oder zu bearbeiten. Für die reine Anzeige von Code ist der
[CodeBlock](/04-components/content/code-block/overview) vorgesehen.

## Best Practices

Achte bei der Verwendung eines CodeEditors darauf, dass die im `language`
Property gesetzte Sprache zum Code-Inhalt passt, damit das Syntax-Highlighting
korrekt dargestellt wird.
