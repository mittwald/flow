# Code-Beispiel

Gib den Inhalt des `<CodeEditor />` über das `value` Property an und setze mit
dem `language` Property die Programmiersprache (s.
[unterstützte language imports](https://github.com/mittwald/flow/tree/main/packages/components/src/components/CodeEditor/languages/all.ts)),
damit der Code korrektes Syntax-Highlighting erhält.

<LiveCodeEditor stretch />

---

# Best Practices

- **Setze im `language` Property die Sprache passend zum Code-Inhalt.** So wird
  das Syntax-Highlighting korrekt dargestellt.
