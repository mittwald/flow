# Verwendung

Verwende ein PasswordCreationField, um ...

- User bei der sicheren Erstellung neuer Passwörter zu unterstützen.
- visuelles Feedback zur Stärke und Gültigkeit eines Passworts bereitzustellen.
- die Generierung sicherer Passwörter innerhalb definierter Richtlinien
  anzubieten.
- Passwortanforderungen transparent und nachvollziehbar zu kommunizieren.

Für die Eingabe bestehender Passwörter eignet sich hingegen ein reguläres
[TextField](/04-components/form-controls/text-field/overview) mit dem Type
`password`.

## Best Practices

Achte bei der Verwendung eines PasswordCreationFields darauf, dass ...

- standardisierte Richtlinien genutzt werden, sofern keine spezifischen
  Anforderungen bestehen.
- selbst formulierte Richtlinien klar und eindeutig für die User verständlich
  sind.

---

# Passwort Richtlinien

Standardmäßig wendet das PasswordCreationField folgende Passwortregeln an:

- Mindestlänge von 12 Zeichen
- Mindestens ein Sonderzeichen enthalten
- Mindestens eine Zahl enthalten
- Darf nicht durch [HaveIBeenPwned](https://haveibeenpwned.com/passwords)
  verboten sein

Alternativ lassen sich eigene Passwortanforderungen definieren. Diese sollten
klar formuliert und für User nachvollziehbar sein.
