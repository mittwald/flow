# Best Practices

- **Zeige höchstens fünf kurze Optionen an.** Ideal ist ein selbsterklärendes
  Wort, höchstens ein bis drei Wörter, ohne dass der Text zweizeilig wird.
- **Stelle die wichtigste Option zuerst.** Sie wird automatisch vorselektiert.
- **Beschreibe die Optionen mit einem
  [Label](/04-components/content/label/overview), falls sie im Zusammenhang
  nicht verständlich sind.** Fehlt das Label, setze ein `aria-label`.

## SegmentedControl vs. RadioGroup

SegmentedControl und
[RadioGroup](/04-components/form-controls/radio-group/overview) haben viele
Gemeinsamkeiten.

<DoAndDont>
  <Plain heading="Verwende ein SegmentedControl, um z. B. ...">
    - eine Einfachauswahl von 2 bis 5 Optionen anzuzeigen.
    - Optionen anzuzeigen, die aus 1 bis 2 Wörtern bestehen.

  </Plain>

  <Plain heading="Verwende eine RadioGroup, um z. B. ...">
    - eine Einfachauswahl von 2 bis ungefähr 7 Optionen anzuzeigen.
    - Optionen mit unterschiedlicher Textlänge darzustellen.

  </Plain>
</DoAndDont>

# Container Breakpoint Size

Sobald der Container schmaler als der gesetzte Breakpoint ist, stellt das
SegmentedControl seine Optionen untereinander dar. Im Default passiert das bei
550 px (`containerBreakpointSize="m"`); über die Property lässt sich die Größe
mit Werten zwischen `xs` und `xl` überschreiben. Achte darauf, dass der Text
auch dann nicht zweizeilig oder unlesbar wird.
