# Verwendung

Verwende einen Focus Task für einen konkreten Vorgang, auf den sich der Nutzer
konzentrieren soll, etwa Registrierung, Anmeldung, Konfiguration oder
Bestellung.

---

# Aufbau

- **Rahmen** – Ein zentrierter, breitenbegrenzter Bereich auf dem
  Hintergrund-Gradienten hält alles im Blick. Der Rahmen ist app-eigenes CSS.
- **Logo** – Über der Card verankert die Marke den Kontext.
- **Content** – Der Content wird in einer
  [LayoutCard](/components/structure/layout-card) dargestellt, mit den Aktionen
  und Formularen direkt darin. So erfüllt der Nutzer eine bestimmte Aufgabe,
  etwa mit einem [Button](/components/actions/button) als primärer Aktion.
- **Fußzeile** – Außerhalb der Card stehen wichtige Verweise, etwa auf
  Datenschutz oder Impressum, als [Links](/components/navigation/link).

---

# Varianten und Abwandlung

## Konfigurations-Aufgabe

Auch eine mehrteilige Aufgabe bleibt ein Focus Task, solange sie ohne Navigation
auf ein Ziel führt. Abgebildet ist ein Konfigurator aus mehreren
[LayoutCards](/components/structure/layout-card).
