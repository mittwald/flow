# Verwendung

Ein Focus Task ist eine einzelne Seite ohne umgebende Navigation. Verwende ihn
für einen klar abgegrenzten Vorgang wie Registrierung, Anmeldung, Konfiguration
oder Bestellung. Ohne Navigation bleibt der Nutzer auf die eine Aufgabe
konzentriert und schließt sie zielgerichtet ab.

---

# Aufbau

- **Content** – Die Aufgabe liegt vollständig in einer
  [LayoutCard](/components/structure/layout-card): Eingaben und Aktionen stehen
  direkt darin, ohne umgebende Navigation.
- **Fußzeile** – [Links](/components/navigation/link) führen zu Verweisen wie
  Datenschutz oder Impressum.

---

# Varianten und Abwandlung

## Konfigurations-Aufgabe

Auch eine mehrteilige Aufgabe bleibt ein Focus Task, solange sie ohne Navigation
auf ein Ziel führt. Abgebildet ist ein Konfigurator aus mehreren
[LayoutCards](/components/structure/layout-card).
