# Verwendung

Eine Simple App führt wenige gleichrangige Bereiche unter einer einzigen,
flachen Navigationsebene zusammen. Verwende sie für ein überschaubares Werkzeug,
dessen Bereiche alle auf einer Ebene liegen. Die flache Struktur macht jeden
Bereich mit einem Klick erreichbar. Sobald eine zweite Navigationsebene nötig
wird, ist es eine [Complex App](/templates/app-shells/complex-app).

---

# Aufbau

- **Header** – Eine [HeaderNavigation](/components/navigation/header-navigation)
  bildet die einzige, flache Navigationsebene über die gleichrangigen Bereiche
  und bietet Raum für bereichsübergreifende Funktionen wie eine Suche oder die
  Profilverwaltung.
- **Content** – Der Inhalt einer Seite wird in der Regel in
  [LayoutCards](/components/structure/layout-card) dargestellt. Typische
  Seitentypen sind beispielsweise [Detailseiten](/templates/seiten/detailseite),
  [Dashboards](/templates/seiten/dashboard) und
  [Übersichtsseiten](/templates/seiten/uebersichtsseite).
- **Footer** – Hier lassen sich [Links](/components/navigation/link) platzieren,
  etwa Verweise auf Datenschutz oder Impressum.
