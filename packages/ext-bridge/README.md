# @mittwald/ext-bridge

The runtime bridge between an **mStudio extension** and the mStudio host: the
extension's context (user, project, extension instance, language, theme) and the
session token your backend exchanges for an mStudio API access token.

Part of [Flow – mittwald design system](https://flow.mittwald.de/).

**[USAGE.md](./USAGE.md)** — the four entry points and which runtime each
belongs in, reading the context, and the auth flow.

Upgrade notes: [MIGRATION.md](./MIGRATION.md).
